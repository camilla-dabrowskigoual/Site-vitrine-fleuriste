🌸 BloomPetals – Site vitrine de fleuriste

## 📖 Présentation

BloomPetals est un projet de site vitrine pour une boutique de fleurs fictive.

Ce site a été réalisé dans le cadre de mon apprentissage du **HTML et du CSS**, à partir d'une maquette.

L'objectif est de créer une page web agréable et structurée pour présenter une entreprise de création florale, ses engagements et ses services.

## 🛠️ Technologies utilisées

- **HTML5** : structure et contenu de la page
- **CSS3** : mise en page et personnalisation du design
- **Google Fonts** : utilisation de la police Pacifico

## ✨ Fonctionnalités et éléments réalisés

- Barre de navigation avec effets au survol (`:hover`)
- Présentation de l'entreprise et de ses engagements
- Galerie de quatre images de fleurs
- Section présentant trois services
- Alignement des éléments avec Flexbox
- Liens « Read more »
- Pied de page

## 🎯 Objectifs pédagogiques

Ce projet m'a permis de pratiquer plusieurs notions de HTML et CSS :

- La structure d'une page HTML
- L'utilisation des classes CSS
- Les marges (`margin`) et les espacements intérieurs (`padding`)
- La mise en page avec `display: flex`
- L'utilisation de `gap`, `flex-direction` et `flex: 1`
- Les effets `:hover`
- La mise en forme des images avec `object-fit: cover`
- L'intégration d'une police Google Fonts

## 🚀 Lancer le projet

1. Télécharger ou cloner le dépôt GitHub.
2. Ouvrir le dossier du projet.
3. Ouvrir le fichier `index.html` dans un navigateur.

Aucune installation supplémentaire n'est nécessaire.
